## 🚀 Getting Started

Follow these steps to explore and run the practicals.

### 1. Clone the repository

```bash
git clone https://github.com/CodeZulqarnain/ML-Lab-2024-SE-07.git
```

### 2. Navigate to the project directory

```bash
cd ML-Lab-2024-SE-07
```

### 3. Create a virtual environment (recommended)

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

On macOS or Linux:

```bash
source .venv/bin/activate
```

### 4. Install the required dependencies

Install the libraries required by the particular practical. For example, if it uses NumPy, Pandas, and Scikit-learn:

```bash
python -m pip install numpy pandas scikit-learn
```

Install additional packages only when required by the experiment. If a `requirements.txt` file is added to the repository, use:

```bash
python -m pip install -r requirements.txt
```

### 5. Run a practical

Open the relevant file inside the laboratory folder using the appropriate environment.

For a Jupyter Notebook:

```bash
python -m pip install notebook
python -m notebook
```

For a Python script:

```bash
python filename.py
```

Replace `filename.py` with the actual script name. Follow any dataset paths and instructions documented in the practical.
